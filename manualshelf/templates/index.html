? ManualShelf — Help & Reference
Getting Started

ManualShelf catalogs files on your computer so you can find and open them quickly. Files stay where they are — ManualShelf only stores metadata and thumbnails.

  1. Click 📂 Add Manuals in the top bar
  2. Paste a folder path and click Scan
  3. Check the files you want to add
  4. Click Add Selected — thumbnails generate automatically
  5. Click any card to open the detail panel and edit metadata
Searching

The search box matches against title, filename, make, model, description, and tags simultaneously.

For PDFs, search also looks inside the document text if you have run Re-index PDFs in Settings. Results that matched on text content show a PDF TEXT badge.

Bulk Editing

To apply tags or a category to many files at once:

  1. Click ☑ Select in the toolbar
  2. Click cards to select them, or Select All
  3. Click ✏️ Edit Selected
  4. Enter tags and/or a category — check Add to existing tags to merge rather than replace
Updating a Manual

When you replace a file on disk with a newer version, re-scan the same folder. Changed files show an amber UPDATE badge and are pre-checked. Selecting them refreshes the thumbnail and file data while keeping all your metadata (title, tags, category, etc.).

Full-Text PDF Search

ManualShelf can search inside PDF text, not just filenames and tags.

  1. Open ⚙ Settings and click 🔍 Re-index PDFs
  2. Indexing runs in the background — no need to wait

New PDFs are indexed automatically when added. Re-run after adding a large batch.

Cross-Computer Setup

To see each other's catalogs across two computers:

  1. On each computer, open ⚙ Settings
  2. Set a unique Computer Name
  3. Set the same NAS Exchange Folder path on both
  4. Check both Push and Pull, then save

Each computer updates the exchange folder every 5 minutes. Remote manuals appear under 📡 Remote Manuals in the sidebar — click any to see its full description, tags, and metadata.
