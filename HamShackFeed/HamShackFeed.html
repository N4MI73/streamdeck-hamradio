Ham Radio Content Aggregator — Help & Tips
📰 Reading the Feed

HamShackFeed pulls together the latest content from ham radio blogs, podcasts, and YouTube channels into a single dashboard. Content is sorted newest first across all sources.

Each card shows the source name, content type, publication date, title, and a short description. Click Open to read the full article or watch the video in a new tab.

Content types are color coded: Blog cyan   Podcast gold   YouTube red

Use the filter buttons at the top to show only one content type. Click the same filter again or click All to return to the full feed.

✓ Read Tracking

Click ● Mark read on any card to mark it as read. Read items dim to 45% opacity but stay visible so you can still access them.

Toggle Unread only in the sidebar to hide all read items and see only fresh content. Toggle it off to show everything again.

Click Mark all read at the top of the feed to clear the entire unread queue at once.

Read state is saved in your browser and survives page refreshes and browser restarts. It is stored per browser — clearing browser data will reset it.
★ Favorites

Hover over any source in the sidebar to reveal the ★ star button. Click it to add that source to your favorites. Up to 5 sources can be favorited.

Favorited sources appear in a panel at the top of the page showing their latest item — perfect for sources you check most frequently. They also remain in the main feed as normal.

Click a gold star to remove that source from favorites. The panel disappears automatically when no sources are starred.

Clicking a favorites card opens that item directly in a new tab.
🎧 Podcast Player

Podcast episode cards show a ▶ Play button when an audio file is available. Click it to start playing directly in the dashboard.

A persistent player bar appears at the bottom of the screen with full controls:

▮▮ / ▶ — Play / Pause
⏮ 15s — Skip back 15 seconds
30s ⏭ — Skip forward 30 seconds
Seek bar — Click or drag to any position
X Close — Stop playback and dismiss the player

The player stays visible as you browse the feed so you can keep reading while listening.

Not all podcast feeds include a direct audio link. If no Play button appears, use Open to visit the podcast page directly.
+ Adding Sources

Click + Add Source and paste any URL. HamShackFeed will auto-detect the type and find the RSS feed:

Blog: Paste the website URL — e.g. https://www.kb6nu.com
HamShackFeed tries /feed automatically (works for most WordPress sites)

Podcast (Podbean): Paste the show URL — feed URL is constructed automatically

YouTube: Paste the channel URL — channel ID is extracted for the RSS feed
e.g. https://youtube.com/@hamradiocrashcourse

The dashboard tests the feed before adding it. If it fails, try adding /feed or /rss to the end of the URL manually.

Apple Podcasts links cannot be used directly. Find the show's own website for its RSS feed URL.
API key required to add sources: HamShackFeed uses rss2json.com to fetch RSS feeds. Without a free API key set in the source code, the rate limit is 1 request per 10 seconds and all adds will fail. Get a free key at rss2json.com and set RSS2JSON_KEY near the top of the <script> block.
✕ Removing Sources

Hover over any source in the sidebar to reveal the ✕ remove button. Click it and confirm to remove that source. All its items disappear from the feed immediately.

Removed sources are saved to local storage. To restore a removed source, use + Add Source to add it again by URL.

⌕ Search

The search bar at the top filters your current feed items in real time as you type. Results match against title, description, and source name.

For longer queries (4+ characters) a DuckDuckGo web search is also triggered automatically, showing ham radio web results below your feed.

Clear the search box to return to the full feed. The filter buttons and source selection still apply while searching.
⚡ Troubleshooting
Feed not loading: The rss2json.com proxy may be temporarily unavailable. Try clicking Refresh. If it persists, the proxy free tier may have hit its daily limit — wait a few minutes and try again.
Add Source fails every time: A free rss2json.com API key must be set in the source code (RSS2JSON_KEY). Without one, requests are throttled to 1 per 10 seconds and will consistently fail. Get a free key at rss2json.com.
No thumbnails on YouTube cards: Try refreshing. Thumbnails are fetched directly from YouTube CDN and should load reliably.
No Play button on a podcast: That episode's RSS entry does not include a direct audio link. Use Open to visit the podcast page instead.
Added source shows no items: The feed URL may be incorrect. Remove it and try again with /feed or /rss appended to the URL.
Read state was reset: Browser data was cleared. Read state is stored in localStorage which is removed when browser history/data is cleared.
📡 About HamShackFeed
