HamShackFeed Pro
Server-Powered Ham Radio Content Aggregator
🖥️ About Pro

HamShackFeed Pro is a locally-hosted server version of HamShackFeed. Unlike the standalone HTML file, Pro stores everything in a SQLite database on your PC — sources, items, and read state are preserved across browser clears and accessible from any device on your network.

No API key required. Pro fetches RSS feeds directly on the server — no rss2json.com proxy needed.
📰 Reading the Feed

Content is sorted newest-first across all sources. Each card shows the source, type, date, title, and description. Click Open to read in a new tab.

Color codes: Blog cyan   Podcast gold   YouTube red
✓ Read Tracking

Click ● Mark read on any card. Read state is stored on the server — it persists across devices and survives browser data clears.

Toggle Unread only in the sidebar to focus on fresh content.
★ Favorites

Hover over a source in the sidebar and click the ★ to favorite it (up to 5). Favorited sources show their latest item in the panel at the top for quick access.

🎙️ Podcast Player

Podcast cards with audio links show a ▶ Play button. Click to open the persistent player bar at the bottom with full controls — play/pause, skip ±15s/30s, seek bar.

+ Adding Sources

Click + Add Source and paste a URL. The server auto-detects the feed and fetches items immediately.

Blog: Paste the site URL — /feed is tried automatically
Podcast: Paste the RSS feed URL directly
YouTube: Use youtube.com/channel/UCxxxxxxx format (not @handles)
Apple Podcasts links cannot be used. Find the show's own website for its RSS feed URL.
↺ Refresh

Feeds refresh automatically every 30 minutes in the background. Click ↺ Refresh to force an immediate update of all sources. The status indicator in the header shows refresh progress and last update time.

⚡ Troubleshooting
Feed not loading: Check the source URL is a valid RSS feed. Try removing and re-adding with /feed or /rss appended.
No items after adding: The server fetches in the background — wait a few seconds and refresh the page.
YouTube not loading: Use the full channel URL format, not a @handle. Find it on the channel's About page.
Server not reachable from another device: Check Windows Firewall allows port 8074, and use your PC's local IP address (e.g. 192.168.1.x:8074).
